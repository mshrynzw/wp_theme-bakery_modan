# 総合テスト

このディレクトリには、手動確認の観点を置きます。
自動テストのコードは置きません。単体は `tests/unit`、結合は `tests/integration` です。

実装がトップページまでつながった段階で、Excel のチェックシートを追加します。

## 前提

```bash
composer test:unit
composer test:integration
pnpm test
pnpm run build
```

テーマを有効化し、外観 > カスタマイズとパンの投稿に、確認用の値を入れてからブラウザで見ます。

## 確認する操作

### 営業状況

- 端末時刻を開店より前、開店ちょうど、カフェ終了ちょうど、閉店ちょうど、閉店後に変えて、ヒーローと店舗情報と PC 背景の文言が揃うこと
- 定休日の曜日に、本日は定休日です、と出ること
- 空欄の定休日では、毎日営業と同じ判定になること
- 不正な営業時刻では「営業時間を確認してください」になること

### 焼き上がり

- 複数パンの時刻が、時刻順の1つの表にまとまること
- 同じ時刻の商品は、管理画面の並び順になること
- 開店前は最初の枠が次の焼き上がりで、「開店と同時に」と出ること
- 営業中は、今より後の最も近い枠だけが次の枠になること
- 最終枠のあと、および定休日は、次の枠が無いこと
- 商品名を押すと、そのパンの詳細が開くこと

### カルーセル

- 季節限定と店内写真を、スワイプ、前後ボタン、キーボードの左右で送れること
- 枚数やドットが、投稿数・写真数と一致すること
- 通年メニューのタブ（すべて / 食事パン / 甘いパン / ドリンク）で件数が合うこと

### ボトムシート

- 商品を開いたとき、下からシートが出ること
- 閉じるボタン、外側のタップ、Esc、つまみの下方向ドラッグで閉じること
- 開いている間、背面がスクロールしないこと
- シート内の「アクセス」「焼き上がり」で、閉じてから該当箇所へ移動すること

### 幅 768px の境界

- 767px 以下では、背景ステージと左の目次が無く、その背景写真のリクエストも出ないこと
- 768px 以上では、幅 420px のカラムの外側に背景が出て、セクションの通過で写真と縦書きが変わること
- 1200px 以上で目次、下部の固定ナビはヒーローを過ぎると出ること

### 動画の遅延読込

- ページ表示直後の通信に、製造動画のファイルが無いこと
- 再生ボタンのあとで初めて動画を読みにいくこと
- 動画ファイルが未設定のときは、プレースホルダーのままでレイアウトが崩れないこと
- ダイアログを閉じると再生が止まること

### あわせて見る

- 住所コピーで、コピー用の1行がクリップボードに入り、成否のトーストが出ること
- 「視差効果を減らす」で、自動スライドと出現アニメーションが止まること
- 画像が1枚も無いセクションでも、見出しと本文が残ること
- パンの個別 URL を直接開いて、価格と本文とトップへの戻りがあること
